fork of https://github.com/robx/pzprjs, with new features:

 - solve recording: click *pzplus -> Play recording* to replay your solve in realtime

 - data entry: times and recordings are automatically saved, and you can also input various subjective stats. note that you have to click outside the comment field for that to save. all stats will be sql queriable at some point

 - the database page direct links to pzplus by default without any need for a userscript (helpful for mobile)

 - dark theme (i'll add a button to toggle it if people want)

 - pause by pressing `p` or clicking "pause"

to self-host, just run `server.py`. config at the top of that file
